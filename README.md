# 🤖 또박이 — 우리 가족 글쓰기 친구

울 · 펄 · 밍 가족이 같은 주제로 손글씨 글쓰기를 하고, AI 선생님에게 첨삭과 채점을 받아 배지를 모으는 웹사이트입니다.

- 인터뷰(날씨, 기분, 관심사 등) → 오늘의 주제와 오늘만의 배지
- 초보 모드: 서론 → 본론①원인 → 본론②해결 → 결론 단계별 안내와 개요 메모
- 손글씨 사진 → 글자 인식 → 첨삭 → 채점(밍은 초3~4 기준, 어른은 어른 기준)
- 1등 🥇 / 2등 🥈 배지, 밍은 🌱 도전 배지도 받을 수 있음

## 필요한 환경변수 (Vercel)
- `ANTHROPIC_API_KEY` : Claude API 키
- `FAMILY_CODE` : 가족 코드 (사이트 입장 비밀번호)
- `KV_REST_API_URL`, `KV_REST_API_TOKEN` : Upstash Redis (Vercel Storage에서 연결하면 자동 입력)
- `RESEND_API_KEY`, `MAIL_TO` : 시상식 후 A5 PDF를 메일로 받기 (Resend)

## 블로그와 인쇄
- 시상식이 끝나면 글이 `/blog.html` 블로그에 자동으로 올라갑니다 (기록을 지워도 블로그 글은 남음).
- 블로그 글에서 "네이버 블로그용 복사"로 다른 블로그에 붙여 넣을 수 있습니다.
- A5 인쇄용 문서(한 사람당 한 장)를 인쇄하거나 PDF로 저장·메일로 받을 수 있습니다.
