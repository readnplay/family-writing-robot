# 🤖 가족 글쓰기 로봇

펄 · 울 · 밍 가족이 같은 주제로 손글씨 글쓰기를 하고, AI 선생님에게 첨삭과 채점을 받아 배지를 모으는 웹사이트입니다.

- 인터뷰(날씨, 기분, 관심사 등) → 오늘의 주제와 오늘만의 배지
- 초보 모드: 서론 → 본론①원인 → 본론②해결 → 결론 단계별 안내와 개요 메모
- 손글씨 사진 → 글자 인식 → 첨삭 → 채점(밍은 초3~4 기준, 어른은 어른 기준)
- 1등 🥇 / 2등 🥈 배지, 밍은 🌱 도전 배지로 10번 중 7번 이상 배지 보장

## 필요한 환경변수 (Vercel)
- `ANTHROPIC_API_KEY` : Claude API 키
- `FAMILY_CODE` : 가족 코드 (사이트 입장 비밀번호)
- `KV_REST_API_URL`, `KV_REST_API_TOKEN` : Upstash Redis (Vercel Storage에서 연결하면 자동 입력)
